# Distraction-Free Writing Mode

A full-screen composition mode that hides all chrome (menus, toolbars, status bar) to let the writer focus entirely on the text. Customizable background color/texture, adjustable text column width, and a gentle fade-in for UI elements when the cursor moves to screen edges.

## Status

Not yet implemented. The app currently always shows the full UI (title bar, menu bar, toolbar, status bar).
