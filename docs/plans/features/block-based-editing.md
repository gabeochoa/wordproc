# Block-Based Editing

Treat every piece of content as a discrete, movable block: paragraphs, headings, images, checklists, code blocks, callouts, toggles, embeds, etc. Blocks can be dragged to reorder, transformed between types (e.g., paragraph to heading), and nested.

## Status

Not yet implemented as a user-facing paradigm. Internally, content elements are discrete in the text buffer, but there's no drag-to-reorder or block transformation UI. Inspired by Notion's block model.
