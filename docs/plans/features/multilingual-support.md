# Multilingual Support

Full multilingual support including: UI localization (translate menus, dialogs, messages), input method editor (IME) support for CJK and other complex scripts, and right-to-left (RTL) text editing for Arabic, Hebrew, and similar languages.

## Status

Multi-script font support exists (Latin, Korean, Japanese, Chinese, Cyrillic, Greek, Arabic, Hebrew, Thai) with lazy loading for CJK. Missing: UI localization, IME support, and RTL editing.
